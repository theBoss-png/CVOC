Quizlet importieren
Text aus einem Quizlet-Set einfügen – die Trennzeichen erkennt CVOC selbst.
So kommst du an den Text
  1. Das Set auf quizlet.com öffnen.
  2. Oben rechts auf ⋯ klicken und Exportieren wählen.
  3. Trennzeichen stehen lassen (Tabulator zwischen Begriff und Definition, Zeilenumbruch zwischen den Karten).
  4. Text kopieren drücken und hier unten einfügen.
Quizlet bietet den Export nur für Sets an, die dir gehören. Bei einem fremden Set kannst du es vorher in dein Konto kopieren – oder du markierst die Karten auf der Seite und fügst sie einfach hier ein, CVOC kommt auch damit klar.
